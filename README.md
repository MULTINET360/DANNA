# Dashboard de estado de cuenta — Danna

Sitio estático elaborado a partir de `DANNA.xlsx`. Resume compras, pagos, productos retirados y saldo pendiente al corte del 31 de agosto de 2026.

## Abrir localmente

Abre `index.html` en un navegador. No requiere instalación ni servidor.

## Publicar con GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube los archivos de esta carpeta a la raíz del repositorio.
3. En **Settings → Pages**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`.
5. Guarda los cambios. GitHub mostrará la dirección pública del dashboard.
